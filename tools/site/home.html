Five minutes, once.

Google TV has no setting for choosing a different home app, so it’s set once from a computer. The command at the top of this page does it for you.

  1. Turn on debugging

    On the TV, open Settings, About, and press OK on the build entry seven times. Then switch on USB or Wireless debugging in Developer options.

  2. Run the command

    Paste it into a terminal on a computer on the same Wi-Fi. It finds the TV and checks it runs Android 12 or newer.

  3. Press Home

    Follow the prompts. When it’s done, shangOS is your home screen. The TV’s own home stays installed as a fallback.

Before you install.

Short answers. The setup page has the long ones.

Will it work on my TV?

It needs an Android TV or Google TV on Android 12 or newer. It was built and measured on one small stick (an onn. Full HD Streaming Device) and hasn’t been tested on every brand, so please tell me what you find. Not for phones, tablets or Fire TV.

What does it change on my TV?

It installs one app and makes it the home screen. The TV’s own home and setup apps stay switched on, so the TV always has somewhere to start. No root, no firmware changes. Full list.

Does it block ads in other apps?

shangOS shows none itself, but it doesn’t change other apps. The setup can optionally switch on an ad and tracker filter for the whole TV (Android’s Private DNS). It’s off by default and has limits, so read them first.

How do updates work?

It never checks for or downloads updates on its own. Run the setup again, or install the new APK over the old one. Releases use the same signing key, so your order, names and wallpaper stay.

Is it safe?

You can check each part yourself: the source is public, releases are signed, and the setup verifies SHA256SUMS before installing. No accounts, no analytics. See the privacy page.

Who makes it?

A hobby project, maintained in spare time under the MIT licence. It began as a fork of Luma TV; see the credits.
