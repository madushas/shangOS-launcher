# Website design (Astra theme)

Status: ported in 0.6.4. Generated by `tools/build-site.py` (the shell, home and 404 come from `tools/site/home.html` and the generator; the doc bodies are the generator's own). Verified in Chromium: light and dark, 1440 and 390 px, axe-core (WCAG 2.0 to 2.2 AA plus best practice) with zero violations, no horizontal overflow, no console errors, no broken internal links or anchors.

## What changed and why it moved the site up

| Area | Before | Now |
|---|---|---|
| First screen | Text-only hero, TV drawn from CSS boxes | Install command and the real launcher screenshot in a TV frame, both above the fold |
| Install | Bottom of page | Top of page, with OS tabs, auto-selected, and a Copy button |
| Rhythm | Identical section headers | Alternating surfaces (`--bg`, `--bg-2`), varied block sizes, one orchestrated load animation |
| Theme | Light-only toggle state | System by default, one toggle, choice remembered, `light-dark()` tokens, no flash |
| Navigation | Different per page | One header on every page; inline when it fits, native popover menu when it does not |
| Terminals | Fixed dark blocks | Theme-aware surfaces, 3:1 borders, prompts and comments excluded from Copy |
| Motion | None | Headline rise, TV settle, tab fade, one looping "grab a tile" demo. All off under `prefers-reduced-motion` |

Theme state lives in `<meta name="color-scheme">` (`light dark`, `light` or `dark`). CSS maps it to `color-scheme`, so `light-dark()` follows it.

## How the pieces connect

- **Header.** `<nav>` holds a `popovertarget` button and the `<ul popover>`. `astra.js` measures the header row; if every link fits it adds `is-wide` and removes `popover`, otherwise the same list opens as a popover. Without JS the popover version is used at every width.
- **Tabs.** Markup: `[data-tabs]` containing `[role=tab]` buttons whose `aria-controls` point at `[role=tabpanel]`. Without JS all panels show, each with a visible title. The OS choice is shared across the page and stored as `shangos-os`.
- **Copy.** Any `.copy` inside a `.term` copies the visible `<code>`, minus `.p` (prompt), `.c` and `.o` (comments, output).
- **Release variables.** `data-rel="version"` and `data-rel="apk-size"` mark values the release CI must fill (now 0.6.1 and 2.9 MB).
- **Placeholders.** `#p1` to `#p3` in `home.main.html` hold `.shot` boxes. Replace each with an `<img width=1280 height=720 loading=lazy alt=...>`.

## Accessibility and browser notes

- Landmarks: skip link, one `<header>`, `<main>`, `<footer>`, labelled `<nav>`s. Heading order is continuous on every page.
- Keyboard: tabs use arrows, Home, End; menu popover closes with Esc; visible 2px focus ring everywhere.
- Contrast: text tokens at least 4.5:1, control borders at least 3:1, checked with axe-core in both themes.
- Needs: `light-dark()`, `:has()`, `popover` (Baseline 2024-2025). Older browsers get the light palette and an unstyled-but-working menu button.
- CSP: `_headers` allows one inline script by SHA-256 (printed by `build.py`; regenerate after editing `BOOT`), Google Fonts, and nothing else. No inline styles are used.
